# 料理カタログ(foods.json)のルール

アプリは、このJSONの料理を読み込みます。アプリに同梱した版と、GitHubの raw URL から取る版があります(`src/config.ts` の `CATALOG_URL`)。

## 料理の `id` は、変えない・消さない・使い回さない(欠番扱い)

- 献立は、料理を `id` で覚えています。メモとレシピのURLも、`id` で保存されています。
- `id` を変える、消す、別の料理に使い回すと、その料理を使った献立の区画が空になったり、別の料理に化けたりします。
- 使わなくなった料理は、JSONから消さずに `"retired": true` を付けて残します(欠番扱い)。
  - 新しい献立の料理選びには出しません。
  - すでに使っている献立には、そのまま出ます。
- 新しい料理は、末尾に足して、新しい `id` を付けます。`id` は `f-` で始まる英数字とハイフンです。
- 直したときは、`version` を1つ上げます。

## 料理の項目

| 項目 | 内容 |
| --- | --- |
| `id` / `name` | 変えない ID と、表示名 |
| `color` | `#RRGGBB`。一覧の絵の背景色 |
| `category` | `rice` `main` `side` `veg` `fruit` `other` |
| `group` | `red`(たんぱく質) `yellow`(エネルギー) `green`(ビタミン) |
| `also` | 兼ねる役(例: `["main"]`)。サンドイッチ、ナポリタンなど |
| `style` | `wa` / `yo`。おまかせで味の方向をそろえるのに使う |
| `tags` | 重ねたくない特徴(`fried` `egg` `fish` など) |
| `face` | `{ "style": "smile", "y": 54, "ink": "light" }`。暗い色は `ink: light` |
| `decor` | 決まった形の飾り(0〜100の正方形に描く。最大20個) |
| `pattern` | ちらす模様(`scatter`) |
| `note` / `url` | おすすめメモ・レシピURL。使う人が書いた内容が、あればそちらを優先します |
